# 🐍 Snake Game Pro

## 🎮 Advanced Modern Snake Game with Mobile & Desktop Support

Snake Game Pro is a modern, interactive, and feature-rich snake game developed using **HTML, CSS, and JavaScript**.

This project includes:
- Smooth gameplay
- Sound effects
- Multiple food types
- Lives system
- Pause/Resume functionality
- Mobile touch controls
- Settings menu
- Responsive design

The game is designed to provide a fun and professional gaming experience on both desktop and mobile devices.

---

# 🚀 Features

## 🟩 Smooth Snake Gameplay
- Responsive and smooth snake movement
- Modern gameplay mechanics

---

## 🍎 Multiple Food System

### 🔴 Apple Food
- Increases score by +1

### 🥛 Special Milk Food
- Increases score by +5

---

## ❤️ Lives System
- Player gets 3 lives
- Losing a life changes ❤️ to 💔
- Continue option available after losing a life

---

## 💀 Game Over System
- Game Over screen after all lives are lost
- Restart option included

---

## ⏸️ Pause & Resume
- Pause the game anytime
- Resume gameplay instantly

---

## ⚙️ Settings Menu

### ⚡ Speed Control
Choose game speed:
- Slow

- High

### 🔊 Volume Control
- Increase sound volume
- Decrease sound volume

## 🔄 Wall Pass Feature

- ⬇️ Down

- ➡️ Right

---

# 🎯 Gameplay Instructions

1. Click **START GAME**
2. Control the snake using keyboard or touch buttons
3. Eat:
   - 🔴 Apples for +1 score
   - 🥛 Milk for +5 score
4. Avoid hitting your own body
5. Use lives carefully
6. Continue playing until all lives are lost

# 💻 How To Run

## Method 1 — Direct Run
1. Download or clone the repository
2. Open `index.html` in browser
3. Start playing

---

## Method 2 — VS Code Live Server
1. Open project in VS Code
2. Install Live Server Extension
3. Right click `index.html`
4. Click `Open with Live Server`
